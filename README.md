# Yrysa Wiki Reader

Современное Flutter-приложение для просмотра случайных статей Wikipedia.

Проект находится в папке `yrys/`.

## Автор

- **Yrysa**
- GitHub: https://github.com/Yrysa

## Возможности

- Случайные статьи Wikipedia.
- Премиальный Material 3 UI.
- Светлая и тёмная тема.
- Градиентный фон, glassmorphism-карточки и мягкие тени.
- Skeleton loading.
- Pull-to-refresh.
- История последних статей в памяти.
- Копирование ссылки, шаринг, открытие Wikipedia и GitHub автора.

## Запуск

```bash
cd yrys
flutter pub get
flutter analyze
flutter test
flutter run
```

Для запуска в Chrome:

```bash
flutter run -d chrome
```
